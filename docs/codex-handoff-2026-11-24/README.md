## Обережно з терміном «затверджено»
Копія JSON фіксує внесений текст, але не завжди дату окремого погодження, фінальний публічний деплой або наявність приватної шпаргалки. Не маркувати весь архів як готовий до повторного використання. Для розходжень — окрема доповідь власнику.

## Основні перевірки перед роботою
1. `git status --short`, `git log -5 --oneline`, гілка й незакомічені правки.
2. Перевірити `games/index.json`, потрібний `games/*.json`, `CHANGELOG.md` та таблицю повторів за всіма 9 JSON.
3. Для фото/відео/аудіо перевірити існування точних шляхів у `public/media` або `public/sounds`, STOP та режими play/pause.
4. Не публікувати приватну шпаргалку у відкритому репозиторії.
5. Не змінювати гру без явного погодження конкретних клітинок.

**Пакет — передача знань, а не доручення самовільно переписувати питання чи деплоїти гру.**
