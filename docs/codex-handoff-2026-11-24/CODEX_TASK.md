# Початкова інструкція для Codex

Ти працюєш з репозиторієм `smokerlol111/mygame`. Твоя задача — продовжувати SMOKERLOL QUIZ, зберігаючи погоджені питання, логіку та стиль власника.

Спочатку прочитай:
1. `docs/codex-handoff-2026-11-24/README.md`
2. `docs/codex-handoff-2026-11-24/EDITORIAL_RULES.md`
3. `docs/codex-handoff-2026-11-24/DECISIONS_AND_OPEN_TASKS.md`
4. `games/index.json`, усі `games/*.json`, `CHANGELOG.md` та інструкції технічних тестів.

Зроби спершу лише READ-ONLY аудит:
- встанови фактичну гілку і останні коміти, статус локальних правок;
- перевір цілісність 9 JSON, кількість клітинок, зіставлення медіа, механік, старту, фіналу, глядачів;
- звір Halloween MP3 для HOST, WAV/MP3 для OBS, відокремлення інших квізів;
- склади перелік потенційних дублів між усіма іграми (не вважай однакову відповідь достатньою умовою дубля; оцінюй задум і факт);
- класифікуй проблеми: підтверджені, можливі, неможливо перевірити без приватних матеріалів;
- НЕ змінюй JSON, код, README/CHANGELOG, не коміть і не деплой без наступного дозволу власника.

Коли власник попросить нові питання — спершу пропонуй кандидатів, не внось їх автоматично. Коли надійде явне затвердження й окреме доручення внести — змінюй тільки названі клітинки і виконуй регресію. Не клади приватну шпаргалку ведучого в публічний GitHub.

Формат першого звіту: 1) поточний стан; 2) що погоджено і присутнє; 3) що не підтверджено; 4) ризики й відкриті задачі; 5) потрібні від власника матеріали.
