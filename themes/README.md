# Теми оформлення SMOKERLOL QUIZ

Кожна тема має окрему папку `themes/<назва>/`: опис, візуальні ескізи та матеріали для подальшої реалізації. Назви папок — латиницею, наприклад `halloween`.

## Каталог

| Тема | Статус | Матеріали |
| --- | --- | --- |
| [Halloween](halloween/README.md) | UI HOST / PLAYER допрацьовано локально 28.10; перегляд усіх трьох екранів | OBS із камерами/чатом/донатами, пульт ведучого, телефон із BUZZ; ескізи й скриншоти браузера |

## Що зберігати в папці теми

- `README.md` — задум, статус погодження й реалізації, особливості HOST / PLAYER / OBS та запропоновані механіки.
- `concepts/` — ескізи екранів. Варіанти зберігати окремими файлами, наприклад `board-v2.png`.
- `previews/` — скриншоти фактичної реалізації, окремо від згенерованих ескізів.
- `assets/` — фони, рамки та інші окремі ресурси, коли вони будуть підготовлені для реалізації.

Нову тему додаємо окремою папкою та рядком у каталог. Статус змінюємо відповідно до фактично виконаної роботи.

`themes/` є бібліотекою дизайнів і документації в репозиторії. Виконувані браузерні ресурси Halloween розміщені в `public/themes/`. Додавання папки до бібліотеки саме по собі не перемикає гру: реалізовану тему потрібно явно вибрати через `uiTheme` у JSON конкретної гри. Сервер передає дозволену тему разом зі станом кімнати та `gameId`.
