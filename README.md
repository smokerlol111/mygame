# СВОЯ ГРА — КІНОХАРДКОР v1.2.5

Deployment-ready онлайн-версія для 4 гравців із окремими сторінками ведучого, телефонів та OBS. Після розгортання гравці можуть підключатися через інтернет з будь-яких мереж.

## Сторінки
- `/host` — ведучий створює кімнату та керує грою.
- `/play` — гравці входять з телефону за кодом кімнати.
- `/screen/ROOM` — чистий екран конкретної кімнати для OBS Browser Source.
- `/health` — health-check для Render.

## Що додано у v1.2.5
- `render.yaml` для Render Blueprint;
- сервер слухає `0.0.0.0` і `process.env.PORT`;
- `/health` для автоматичної перевірки працездатності;
- коректне завершення процесу на `SIGTERM`;
- окрема інструкція `RENDER_DEPLOY.md`;
- підготовлено для одного Render Web Service із Socket.IO/WebSocket.

## Локальна перевірка
```bash
npm install
npm start
```
Після цього відкрийте `http://localhost:3000/host`.

## Render
Найпростіший шлях — GitHub + Render Blueprint. Повна інструкція лежить у `RENDER_DEPLOY.md`.

Після деплою, наприклад на `https://svoja-gra-kinohardkor.onrender.com`:
- ведучий: `/host`
- гравці: `/play`
- OBS: `/screen/ABCD`

## Механіки гри
- до 4 гравців;
- room code;
- reconnect гравця через локальний ID;
- reconnect ведучого через секретний token;
- два раунди 5×5;
- перший BUZZ блокує інших;
- після неправильної відповіді інші можуть натискати;
- правильна відповідь +вартість, неправильна −вартість;
- 2 автоматичні «Коти у мішку» у другому раунді;
- фінальні таємні ставки;
- 30-секундний фінал;
- приватні фінальні відповіді;
- clean OBS screen;
- питання зберігаються в `questions.json`.

## Важливо
Кімнати зберігаються в RAM. Використовуйте **один instance**. Перезапуск сервера або новий deploy скидає активні кімнати. Для масштабування на кілька instances потрібне спільне сховище стану, наприклад Redis.


## Зміни v1.2.5

- Виправлено автоматичне повернення телефона у стару кімнату.
- Якщо `/play?room=XXXX` містить інший код, старий `playerId` не використовується.
- Додано кнопку **«Вийти з кімнати»** на телефоні з очищенням локальної сесії.
- Якщо ведучий закрив кімнату, телефони повертаються на екран входу.
- На HOST відновлена кімната тепер одразу рендериться правильно, без кнопки «Створити онлайн-кімнату».
- Додано кнопку **«Нова кімната»** в лобі ведучого.
- Виправлено відображення фінальних відповідей для перевірки ведучим.

## Що виправлено у v1.2.5

- сервер тепер віддає `/questions.json`, тому `/host` і `/screen` отримують дані гри;
- після створення або відновлення кімнати стартова кнопка зникає і відкривається лобі;
- якщо дані питань не завантажилися, HOST/SCREEN показують явну помилку замість «завислого» інтерфейсу.


## Що нового у v1.2.5

- Під час BUZZ у ведучого є кнопка **«Ніхто більше не відповідає»**.
- Якщо всі підключені гравці вже відповіли неправильно, сервер автоматично показує правильну відповідь.
- Після завершення питання HOST показує причину: правильна відповідь / усі помилилися / ніхто не відповів.
- Після показу відповіді є одна зрозуміла кнопка **«До дошки»**.


## Виправлення v1.2.5

- Автоматичний показ правильної відповіді більше не залежить від статусу `connected`.
- Якщо гравець тимчасово відключився, неправильна відповідь іншого гравця не завершує питання достроково.
- Автоматичне завершення відбувається тільки коли всі гравці кімнати вже відповіли неправильно.
- Ведучий може вручну завершити питання кнопкою **«Ніхто більше не відповідає»**.
