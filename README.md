## Архівний опис — СВОЯ ГРА / КІНОХАРДКОР v1.4.1

Deployment-ready онлайн-версія для 4 гравців із окремими сторінками ведучого, телефонів та OBS. Після розгортання гравці можуть підключатися через інтернет з будь-яких мереж.

## Сторінки
- `/host` — ведучий створює кімнату та керує грою.
- `/play` — гравці входять з телефону за кодом кімнати.
- `/screen/ROOM` — чистий екран конкретної кімнати для OBS Browser Source.
- `/health` — health-check для Render.

## Що додано у v1.4.1
- `render.yaml` для Render Blueprint;
- сервер слухає `0.0.0.0` і `process.env.PORT`;
- `/health` для автоматичної перевірки працездатності;
- коректне завершення процесу на `SIGTERM`;
- окрема інструкція `RENDER_DEPLOY.md`;
- підготовлено для одного Render Web Service із Socket.IO/WebSocket.

## Локальна перевірка
Потрібен Node.js 20.12 або новіший. При запуску сервер автоматично читає `.env` у корені проєкту:
`PORT`, `DATABASE_URL`, `DISCORD_BOT_TOKEN`, `DISCORD_GUILD_ID` та `DISCORD_VOICE_CHANNEL_ID`.
Заповніть параметри Discord у цьому файлі один раз. Змінні середовища запуску мають пріоритет над `.env`.
Без файлу `.env` сервер також працює; бот запускається лише за наявності всіх трьох параметрів Discord.

Для спільної статистики гри задайте `DATABASE_URL` у локальному `.env` — сервер використовуватиме PostgreSQL для сезонів і збережених результатів. Без цієї змінної статистика зберігається в `data/seasons.json`. Після зміни `.env` перезапустіть сервер; перевірте `/api/seasons`: поле `storage` має бути `postgres`. `.env` містить секрети та не додається до Git.

```bash
npm install
npm start
```
На Windows `npm start` запускає гру на порту **3100** і Tailscale Funnel; відкрийте `http://localhost:3100/host`. Потрібні встановлений та авторизований Tailscale і доступ до Funnel.
Запуск автоматично записує публічну HTTPS-адресу Funnel у локальний файл `.funnel-url` (не додається до Git). Посилання для гравців, посилання для глядачів і QR використовують цю адресу, навіть коли ведучий та OBS відкриті через `localhost`. Для власного домену можна задати `PUBLIC_URL=https://ваш-домен` у `.env` і перезапустити сервер; ця змінна має пріоритет над адресою Funnel. Після першого встановлення цього виправлення перезапустіть сервер перед новою грою та оновіть сторінку ведучого й OBS.
Для запуску лише сервера використовуйте `npm run start:server` (порт із `PORT` або 3000). На Linux, зокрема Render, `npm start` запускає лише сервер.

## Render
Найпростіший шлях — GitHub + Render Blueprint. Повна інструкція лежить у `RENDER_DEPLOY.md`.

Після деплою, наприклад на `https://svoja-gra-kinohardkor.onrender.com`:
- ведучий: `/host`
- гравці: `/play`
- OBS: `/screen/ABCD`

## Механіки гри
- до 4 гравців;
- room code;
- reconnect гравця через локальний ID;
- reconnect ведучого через секретний token;
- два раунди 5×5;
- перший BUZZ блокує інших;
- після неправильної відповіді інші можуть натискати;
- правильна відповідь +вартість, неправильна −вартість;
- 2 автоматичні «Коти у мішку» у другому раунді;
- фінальні таємні ставки;
- 30-секундний фінал;
- приватні фінальні відповіді;
- clean OBS screen;
- питання зберігаються в `questions.json`.

## Важливо
Кімнати зберігаються в RAM. Використовуйте **один instance**. Перезапуск сервера або новий deploy скидає активні кімнати. Для масштабування на кілька instances потрібне спільне сховище стану, наприклад Redis.
