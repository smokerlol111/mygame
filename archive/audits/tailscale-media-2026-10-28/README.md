# Grand Final — перевірка медіа через Tailscale Funnel

Дата: **28.10.2026**. Код продукту: `92f84401dbd618250e21c092253c1dad26cc5660`. Функціональний код гри й конфігурацію Funnel не змінено.

**Перевірений шлях передачі працює:** файли, часткові завантаження, Socket.IO WebSocket / HTTP polling та віддалене керування браузерними плеєрами. Охоплено всі 29 медіафайлів Grand Final: 18 зображень, 5 MP3 і 6 MP4. Це перевірка з цього ПК через публічний вхід Funnel; незалежні телефони та інші мережі не використовувались.

## Який шлях перевіряли

- Tailscale працює; Funnel на HTTPS `443` направляє запити на `http://127.0.0.1:3100`. Файл `.funnel-url` збігається з активною конфігурацією. Налаштування читалися, але не змінювалися.
- Звичайний DNS цього ПК повертає адресу tailnet `100.101.9.49`, тому просте відкриття URL на цьому комп'ютері не доводить проходження публічного тунелю.
- Сценарій прочитав публічний DNS через DNS-over-HTTPS, примусово направив Node HTTPS/WebSocket/polling і Edge на публічний ingress та зберіг правильне ім'я для TLS/SNI.
- Повний прохід використовував `185.40.234.75`, контрольний прохід плеєрів — `185.40.234.198`. Перевірка сертифіката успішна, HTTPS — TLS 1.3. Адреси фактичних відповідей Edge також є публічними ingress-адресами, а не `100.x` / localhost.
- Публічний URL і `/public-config.js` перевірено. Ключ HOST читається локально без виведення чи запису в звіт.

## Поведінка аудіо й відео

- **Відео:** HOST передає керування PLAYER і OBS. Отримувачі беруть сам файл по HTTPS; Socket.IO передає команди, а не відеопотік.
- **Аудіо:** HOST керує відтворенням OBS. PLAYER має власний аудіоплеєр; відтворення на телефоні запускає гравець. Відсутність автоматичного запуску аудіо від HOST на PLAYER відповідає поточній реалізації.
- **Фото:** питання й адреса зображення надходять у стані кімнати; кожний клієнт завантажує зображення через HTTPS. Власна тестова кімната проходила серверні події вибору питання, а не підміну стану в браузері.
- STOP-мітки локально перевірені попереднім [аудитом стандартної теми](../grand-final-standard-2026-10-28/README.md). Цей Funnel-прохід перевіряв передачу файлів і play/pause/seek; покадрова одночасність STOP між незалежними пристроями не вимірювалася.

## Межі висновку

- Гучномовці, навушники й захоплення звуку реальною програмою OBS не перевірялися. Edge працював із вимкненим звуковим виходом; перед перевіркою дистанційного запуску та сама медіаелемента була активована дією користувача. На телефоні все одно потрібна звичайна взаємодія користувача з грою; правила Safari/iPhone окремо не перевірялися.
- Приймачі працювали на цьому ПК, але мережевий маршрут примусово проходив через публічний Funnel. Затримки мобільних операторів, Wi-Fi гравців, незалежні телефони й довга трансляція цим не підтверджуються.
- Tailscale офіційно зазначає, що [Funnel має нерегульовані обмеження пропускної здатності](https://tailscale.com/docs/features/tailscale-funnel#requirements-and-limitations). Результат короткого виміру не гарантує відсутності буферизації за іншого навантаження.
- Незалежне відкриття URL вебінструментом не було доступне; його помилка не використовується як доказ недоступності сервера. Перевірений маршрут підтверджується фактичними IP HTTPS-відповідей, сертифікатом та контрольними сумами.

## Відтворення

Потрібні запущений сервер гри на 3100, уже налаштований Funnel, Microsoft Edge та локальний ключ HOST у середовищі або `.env`.

```powershell
node tests/ai_repro/tailscale_media_preflight.js --browser
node tests/ai_repro/tailscale_media_preflight.js --browser --control-only
```

Сценарій не запускає/перезапускає сервер і не налаштовує Tailscale. Створює й закриває власну кімнату на чинному сервері; не викликає запис результатів сезону.

[Повний прохід: файли, ділянки, доставка й відповіді браузера](results.json). [Фактичні play/pause/seek плеєрів](control-results.json).

Звіт та інструмент збережені локально. Коміт, push і деплой цього етапу не виконувалися; нову версію релізу не призначено.
