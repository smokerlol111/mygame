- R17 перевіряє звичайну кнопку BUZZ для несинхронізованого клієнта; це її чинне обмеження. Для аварійного відкриття є окрема команда.
- R07/R08 очікують готовий фінал через 100 мс з ненадісланою відповіддю, хоча чинне фінальне вікно становить 2 секунди. Їхній null/error не замінює актуальні перевірки фіналу.

## Межі та незмінність даних

Кожен тестовий сервер мав випадковий локальний порт, окреме тимчасове JSON-сховище й власний шлях до .env у тимчасовому каталозі замість користувацького .env; DATABASE_URL і Discord-секрети вилучені з тестового оточення. Жодна перевірка не запускала tailscale_media_preflight і не змінювала чинний сервер/Funnel.

Усі дев'ять запусків runner підтвердили незмінність захищених файлів і локальної історії сезонів до/після тестів. Окремий git diff для storage.js, games, public, package.json і package-lock.json порожній. [Останній повний маніфест до](run-1795346340611/protected-files-before.json) і [після](run-1795346340611/protected-files-after.json).

Не перевірено фізичні телефони/iPhone/Safari, реальний OBS-композитор, камери/VDO.Ninja, чутний звук у колонках/навушниках, живий Discord, реальний PostgreSQL, зовнішню мережу та довгий ефір. Наявність класичного квізу не тестувалася: його ще не реалізовано.
