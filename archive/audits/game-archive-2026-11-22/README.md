## Межі

Ізольовані сервери мають випадкові порти й тимчасове сховище без користувацького .env, DATABASE_URL та Discord-секретів. Сезонні результати не переписувалися, медіа не переносилися з public, чинний сервер/Funnel/бот не перезапускалися. Живі кімнати не змінювалися. На вже запущеному сервері меню оновиться після наступного запуску; він зчитує каталог у пам’ять при старті.

Фізичні телефони й OBS тут не тестувалися. Старі обмеження вихідного контенту, включно з legacy numeric, збережені в архіві без виправлень. Номер релізу, опублікована контрольна точка, коміт/main/push/деплой не змінені.
