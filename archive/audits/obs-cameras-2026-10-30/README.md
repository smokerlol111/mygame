## Поведінка під час гри

| Подія | Місця під камери |
| --- | --- |
| Дошка → питання → відповідь → наступне питання | Координати ті самі; змінюється ігровий контент |
| Фото, відео, аудіо, спецпитання | Розміщення зберігається |
| Інший гравець відповідає / змінилися бали | Оновлюються підпис і підсвічування; окреме відеоджерело OBS гра не перемикає |
| Сортування першого ходу | Змінюється порядок ходів; `cameraSlot` зберігається |
| Пауза / фінал / закриття кімнати | Рамки залишаються; ховати зовнішні камери, якщо потрібно, слід у OBS |
| Повернення гравця із ключем | Повертається на своє місце; це не перевірка повернення відеопотоку |
| Ручний вихід | Місце звільняється; окреме джерело OBS саме не вимикається. Новачку у лобі треба вручну зіставити камеру |
| Halloween → стандартна тема | Halloween-рамки прибираються; окремі камери OBS автоматично не пересуваються |
| Зміна розміру Browser Source | Рамки перераховуються за vw/vh; попередні координати зовнішніх джерел можуть перестати збігатися |

## Налаштування OBS і VDO.Ninja

1. Тримати гру й камери в одній сцені під час питань: переходи гри не потребують перемикання сцен OBS.
2. Зафіксувати ігровий Browser Source на **1920×1080** і заблокувати джерела від випадкового пересування. Масштабування всього готового кадру для трансляції відрізняється від зміни viewport самого Browser Source.
3. У Browser Source камер вимкнути **Shutdown source when not visible** і **Refresh browser source when scene becomes active**. Перше вивантажує сторінку прихованого джерела, друге перезавантажує її при активації сцени: [офіційний опис OBS](https://obsproject.com/kb/browser-source). Для вебкамери ведучого між сценами можна вимкнути **Deactivate when not showing**: [Video Capture Device](https://obsproject.com/kb/video-capture-sources/).
4. Кожному гравцю VDO.Ninja призначити власний постійний stream ID (`push`) та відповідне посилання перегляду в OBS. Новий випадковий ID не відповідає старому індивідуальному джерелу; двом гостям не слід давати один `push`: [документація VDO.Ninja](https://docs.vdo.ninja/common-errors-and-known-issues/already-in-use-or-claimed-errors). Той самий ID зберігає адресу, але не гарантує відсутність перерви мережі чи повторного дозволу камери.
5. Зіставити stream ID з номером камери на HOST вручну: `cameraSlot` гри та ID потоку VDO.Ninja — незалежні системи, автоматичного зв'язування немає.
6. Для іншої теми підготувати інше розташування джерел OBS і перемикати його разом із темою.

Гра не приймає живе відео й не перевіряє його наявність. Напис «НЕ В МЕРЕЖІ» відображає підключення гравця до гри; камера може мати інший стан. Вміст `.halloween-camera` перебудовується при зміні даних; вручну вставляти туди iframe/video замість окремих OBS-джерел цей аудит не рекомендує.

## Орієнтир розміщення у 1920×1080

Виміряні внутрішні відеовікна, CSS px. У OBS сцена та ігровий Browser Source мають збігатися 1:1:

| Вікно | X | Y | Ширина | Висота |
| --- | ---: | ---: | ---: | ---: |
| Гравець 1 | 43,23 | 830,23 | 340,72 | 194,78 |
| Гравець 2 | 401,31 | 830,23 | 340,72 | 194,78 |
| Гравець 3 | 759,39 | 830,23 | 340,72 | 194,78 |
| Гравець 4 | 1117,47 | 830,23 | 340,73 | 194,78 |
| Ведучий | 1475,58 | 187,19 | 401,19 | 225,66 |

Відео вписувати зі збереженням пропорцій усередину цих меж, залишаючи видимими зовнішню рамку та підпис із балами. Геометрія 1280×720 має власні значення в JSON.

## Знімки та межі перевірки

[Дошка](board.png), [фото](photo-0.png), [пауза](paused.png), [фінальні результати](final_result.png). Імена й контент демонстраційні. Камер на знімках немає: перевірено місця під джерела.

OBS Studio, реальні вебкамери, потоки VDO.Ninja, WebRTC-відновлення, звук, повільні/незалежні мережі, блокування телефонів і довгий ефір **не перевірені**. Немає підстав гарантувати, що реальна камера ніколи не зникне. Потрібен окремий прогін з реальними джерелами OBS, вимкненням/поверненням однієї камери та переходом між сценами.

Код HOST / PLAYER / OBS / сервера, медіафайли й ігрові дані не змінено. Бойові кімнати, сервер і Funnel не перезапускалися. Коміт, push, деплой і новий реліз не виконувалися.
