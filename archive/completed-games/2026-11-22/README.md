# Архів завершених ігор — 2026-11-22

Сезон 1: перші чотири набори; Сезон 2: чотири season2-набори; Halloween — окрема спецгра. Завершення підтверджено власником, фактичні дати проведення тут не призначаються.

Оригінальні JSON у games/ збережені побайтово. QUESTION_BANK.md містить єдиний читабельний довідник усіх питань; його робоча копія — archive/QUESTION_BANK.md у корені проєкту. question-records.json — технічний перелік для перевірки повноти.

ZIP містить JSON, довідник, маніфест і всі 136 медіафайлів за їхніми public-шляхами. Це архів контенту, не резервна копія сервера, статистики, БД або приватних шпаргалок. Налаштування питань, STOP, поетапне відкриття, ставки/спецмеханіки та редакторські позначки збережені в оригінальних JSON.

Перевірка: node scripts/archive-completed-games.js --verify. Для відновлення розпакуйте ZIP в окрему папку; копії JSON беріть із archive/completed-games/2026-11-22/games/, медіа — із public/. Повернення в меню виконується вибірково через enabled у чинному games/index.json; весь старий індекс поверх нових ігор не копіюйте.

Чинні файли games/*.json залишені на місці для сумісності та повторного відтворення; усі дев’ять записів у робочому індексі позначені archived/disabled. Поточний сервер читає каталог при старті: зміни меню застосуються після наступного запуску. Сервер не перезапускався.
