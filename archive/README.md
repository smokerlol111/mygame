# Архів

## Завершені ігри двох сезонів і Halloween — 22.11.2026

- [Спільний файл усіх питань і відповідей](QUESTION_BANK.md) — поповнюваний довідник для підготовки наступних ігор. Архівна частина містить 516 записів: 450 основних клітинок, 9 стартових, 9 фінальних і 48 глядацьких; усередині збережено 18 підпитань триплетів і 6 альтернатив Кота. Є гра, сезон/спецгра, раунд, категорія, ID, бали, медіа та повні вихідні механічні/редакторські позначки. Кожне нове затверджене питання одразу додається в розділ «Нові затверджені питання» після перевірки всього банку на точні та змістові повтори; порядок закріплений у [AGENTS.md](../AGENTS.md).
- [Незмінний знімок 9 наборів](completed-games/2026-11-22/README.md), [маніфест SHA-256](completed-games/2026-11-22/manifest.json).
- [Локальний ZIP із JSON і 136 медіафайлами](completed-games/2026-11-22/games-and-media.zip) — приблизно 146 МіБ, 152 перевірені файли всередині.

Усі дев’ять ігор підтверджені власником як завершені й позначені `enabled:false` / `archived:true` у робочому `games/index.json`. Каталог читається сервером при запуску: меню зміниться при наступному запуску, поточний сервер не перезапускався. Нові ігри надалі додаються звичайними активними записами індексу.

ZIP і його загальна контрольна сума — локальні копії, виключені з Git через розмір; JSON, довідник, план пакування й хеші в маніфесті придатні для збереження в репозиторії. Медіафайли залишилися на попередніх public-шляхах. Якщо після копіювання репозиторію ZIP відсутній, `node scripts/archive-completed-games.js --package` збере його з цих копій і медіа. Команда не перезаписує наявний ZIP. `node scripts/archive-completed-games.js --verify` перевіряє архівні JSON, банк, кожен ZIP-файл та загальну SHA-256.

Це архів контенту. Результати гравців, таблиці сезонів, база даних і приватні шпаргалки сюди не експортувалися. Дата 22.11.2026 — дата знімка, не призначена дата проведення ігор. Кореневий `questions.json` є точним дублем Кінохардкору: копію збережено в `legacy/`, але 50 питань не продубльовано в спільному банку.

До робочого `QUESTION_BANK.md` додано спільний тематичний покажчик усіх 540 записів і вкладених питань; початковий архівний блок не змінено. `scripts/build-question-topic-index.js --verify` перевіряє відповідність покажчика. Нова випадкова гра з категоріями читає машинний знімок для створення окремого набору в пам'яті, зберігаючи початкові ID; завершені набори не повертаються в меню. [Порядок роботи](../server/modes/board/RANDOM.md).

Нові затверджені питання додаються за [правилами й шаблоном](QUESTION_BANK_RULES.md) з основною темою та підкатегорією, для основного поля — із рівнем 1–5. Вони одразу включаються у тематичний покажчик і сумісні випадкові пули через спільний каталог; незмінний знімок не переписується. Команда побудови/`--verify` перевіряє нові метадані, але не замінює ручну перевірку фактів і змістової схожості.
